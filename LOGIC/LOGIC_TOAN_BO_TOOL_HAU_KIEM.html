Cơ Chế Gửi 2 Lớp (Dual-Engine Fail-Safe)

Khi spam ảnh và thông điệp vào nhóm:

  • Lớp 1: Ưu tiên gọi API Bot Telegram (URL_SEND_PHOTO) với Bot Token 8810108114:AAER-s5oEc3pAoggenGm0R5fjA3xMDdQswM.
  • Lớp 2: Nếu Bot báo lỗi (do Bot chưa được add vào nhóm, hoặc nhóm chuyển sang Supergroup), hệ thống lập tức tự động fallback sang User Client (Telethon cá nhân) để gửi tin, đảm bảo 100% tin nhắn đến tay Siêu thị.
